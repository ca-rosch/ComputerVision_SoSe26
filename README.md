# ComputerVision_SoSe26
Find all code for the final project report here.

### Jupyter Notebooks
- EDA.ipynb contains the code for the exploratory data analysis (see results section)
- model_training.ipynb contains all code for the training of the EfficientNet for chest X-ray classification

### results 
Contains checkpoints, history and metrics for the final experiment run with the results used in the report. The experiment was run three times with different seeds (42, 43, 44).

### plots 
Contains all plots used in the report.
